# 📋 Análise e Projeto de Sistemas

Repositório com materiais, exercícios e projetos desenvolvidos na disciplina de Análise e Projeto de Sistemas.

## 🎯 Sobre a disciplina

Disciplina voltada para o estudo de metodologias e técnicas de análise, modelagem e projeto de sistemas de software, abordando conceitos como levantamento de requisitos, modelagem UML, diagramas de caso de uso, classes, sequência e atividades.

## 📚 Conteúdos abordados

- Engenharia de requisitos
- Análise orientada a objetos
- Projeto de sistemas
- Documentação de software

## 📁 Organização do repositório

```
├── Unidades/       # Exercícios práticos da disciplina divididos por aulas
└── Projeto APS/        # Projeto desenvolvido ao longo do semestre  
```
