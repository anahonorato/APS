
# 📚 Unidade 2 – Análise e Projeto de Sistemas de Informação

## 📅 20/08/2026

### 📖 Conteúdo da aula

Nesta unidade, serão abordados os principais conceitos relacionados à Análise e ao Projeto de Sistemas de Informação, com foco nos fundamentos da Engenharia de Software e na utilização de ferramentas para modelagem de sistemas.

### 📝 Tópicos estudados

- **Introdução à Análise e Projeto de Sistemas de Informação**
  - Conceitos e importância da análise de sistemas.
  - Etapas do projeto de sistemas de informação.

- **Conceitos e elementos fundamentais da Engenharia de Software**
  - Definição de Engenharia de Software.
  - Características fundamentais.
  - Tipos de modelagens de software.

- **Ferramentas CASE**
  - Conceito e finalidade das ferramentas CASE.
  - Ferramentas de apoio ao desenvolvimento de software.
  - Utilização de ferramentas CASE para criação e desenho de diagramas UML.

### 🎯 Objetivos de aprendizagem

- Compreender os fundamentos da Análise e Projeto de Sistemas de Informação.
- Conhecer os conceitos e as características da Engenharia de Software.
- Identificar os diferentes tipos de modelagem de sistemas.
- Entender a importância das ferramentas CASE.
- Conhecer ferramentas utilizadas na elaboração de diagramas UML.
